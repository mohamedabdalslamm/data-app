NovaSaaS Landing Page Template

Thank you for purchasing NovaSaaS! This documentation will guide you through the file structure, customization options, and how to preview the template.

File Structure

  • index.html – main landing page
  • style.css – styles and responsive layout
  • script.js – testimonial slider and utilities
  • assets/ – placeholder images and icons

Customizing Colors & Fonts

Open style.css. At the top you'll find global styles for fonts, colors, and spacing. Replace the values of background, color, and font families to match your brand. Icons and images are located in the assets/ folder. Swap them with your own assets using the same file names.

Editing Sections

Each major section is wrapped in a descriptive tag (e.g., <section id="features">). Adjust or rearrange these blocks as needed. The pricing tiers are built with flexible div elements so you can easily add or remove plans.

Previewing the Template

Simply open index.html in your web browser. For the best experience, use a modern browser like Chrome or Firefox. No additional build tools are required.
